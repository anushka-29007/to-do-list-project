# To-Do List Application

A To-Do List web application built using Node.js, Express.js, EJS, CSS, and MongoDB.

## Features

- Add tasks
- View tasks
- Update existing tasks
- Simple and user-friendly interface

## Technologies Used

- Node.js
- Express.js
- EJS
- CSS
- MongoDB

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/anushka-29007/to-do-list-project.git
   ```

2. Open the project folder:

   ```bash
   cd to-do-list-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your MongoDB connection as required by the application.

5. Start the application:

   ```bash
   node index.js
   ```

6. Open the local URL displayed by your application in your browser.
